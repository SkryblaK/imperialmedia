## 🚀 Getting Started

### Prerequisites

- **Node.js** `[v20+]`
- **npm** / **pnpm** / **yarn** / **bun**
- A **Supabase** project (URL and keys)
- Access to this private repository

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/SkryblaK/imperialmedia.git

# 2. Move into the project
cd imperialmedia

# 3. Install dependencies
npm install

# 4. Set up environment variables
cp .env.example .env.local

# 5. Start the development server
npm run dev
```

Then open **http://localhost:3000** in your browser.

<details>
<summary><b>📦 Adding shadcn/ui components</b></summary>

```bash
npx shadcn@latest add breadcrumb collapsible card dropdown-menu input input-group field label separator sonner tabs textarea tooltip
```

</details>

## 🔑 Environment Variables

Create a `.env.local` file in the project root:

```env
# App
NEXT_PUBLIC_SITE_URL=https://www.imperialmedia.na

# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# Email / Contact form
[EMAIL_API_KEY]=
[CONTACT_RECEIVER_EMAIL]=

# Other
[ANY_OTHER_KEY]=
```

> ⚠️ **Never commit `.env.local`.** `SUPABASE_SERVICE_ROLE_KEY` must stay server-side only. Keep an `.env.example` with empty values instead.
